# Use a dedicated Exness demo account for Phase 1, not the existing live account

Phase 1 (Backtest + Paper Trading) must never place a real order. The user already has a live Exness MT5 account, which could have supplied identical market data. We chose to isolate risk at the account level instead: Phase 1 connects only to a separate, newly-opened Exness demo account, and the live account is not referenced anywhere in code or config. This removes the entire class of "a bug in the order-execution path sends a real order" risk at the source — a demo account is structurally incapable of holding real funds — rather than relying on application-level checks, which could themselves be buggy. The live account stays out of scope entirely until a future phase explicitly designs the transition to Live Trading.
