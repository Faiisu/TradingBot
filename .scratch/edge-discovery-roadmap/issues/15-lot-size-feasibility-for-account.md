# 15: ตรวจว่าทุนพอส่งออเดอร์จริงไหม (lot ขั้นต่ำ/step) ตามขนาดบัญชีที่ตั้งไว้

**What to build:** แปลงทุก position เป็นหน่วย lot ของบัญชีจริง แล้วแสดงว่า candidate และ Ensemble ส่งออเดอร์จริงได้หรือไม่ที่ขนาดบัญชีที่ตั้งไว้

ค่าเริ่มต้นคือ **$5,000** ตามบัญชี demo ปัจจุบัน และปรับเป็น config ได้

ข้อมูลจริงวันที่ 2026-09-15 (XAUUSDm):
- ขนาดสัญญา 100 oz, lot ขั้นต่ำ 0.01 (= 1 oz ≈ $4,300 notional), step 0.01, leverage 1:2000
- Ensemble ปัจจุบันมี 36 สมาชิก แต่ละตัวได้ทุน ~$139 และถือ notional ได้ ~$28 ซึ่ง **เล็กกว่า lot ขั้นต่ำประมาณ 150 เท่า** จึงส่งออเดอร์จริงไม่ได้เลย

ถ้า MT5 เชื่อมต่ออยู่ ให้อ่านขนาดสัญญา, lot ขั้นต่ำ และ step จากข้อมูล symbol ของ MT5
