# 07: Swap ย้อนหลังตามประวัติดอกเบี้ย

**What to build:** Backtest 9 ปีต้องคิดค่า swap ข้ามคืนตามยุคนั้นๆ ไม่ใช่ใช้ค่า swap ของวันนี้ (long −534 points ต่อคืน) กับทุกปี เพราะช่วงปี 2017–21 ดอกเบี้ยต่ำมาก ต้นทุนการถือ long จึงต่างจากวันนี้มาก

วิธี:
1. สร้าง swap รายวันจากประวัติดอกเบี้ยนโยบาย ใช้ series สาธารณะที่ดาวน์โหลดได้โดยไม่ต้องใช้ API key แบบเดียวกับ real yield
2. บวก markup ของ broker ที่ calibrate ให้ตรงกับ swap ของ MT5 วันนี้

**Blocked by:** 03 — ประวัติ Exness 9 ปี; 06 — ต้นทุนตาม spread จริง

**Status:** ready-for-agent

- [ ] Swap ต่อคืนเปลี่ยนตามวันที่ และช่วงล่าสุดตรงกับ swap long/short ปัจจุบันจาก MT5 ภายในค่าคลาดเคลื่อนที่กำหนด
- [ ] Series ดอกเบี้ยถูกดาวน์โหลดและ cache ไว้ ถ้าดาวน์โหลดไม่สำเร็จต้องรายงาน ห้ามข้ามเงียบๆ
- [ ] หน้า Backtest แสดง swap รวมที่จ่ายต่อ candidate พร้อมผลเมื่อ swap = 0 และผลเมื่อใช้ swap วันนี้ตลอดช่วง เพื่อเป็นขอบบนและขอบล่าง
